# JavaScript Conditions: Order Validation

A JavaScript exercise about conditional logic and validating a purchase against a customer's available balance.

## What it does

The `makeTransaction(quantity, pricePerDroid, customerCredits)` function calculates the order total. It returns an insufficient-funds message when the balance is too low, or a formatted order confirmation when the purchase can be completed.

## Concepts practiced

- Function parameters and return values
- Arithmetic expressions
- `if / else` conditional statements
- Comparison operators
- Template literals and test calls

## Run locally

Open `index.html` in a browser and inspect the results in the developer console.

## Project context

A small GoIT JavaScript homework exercise focused on branching logic and basic business-rule validation.
